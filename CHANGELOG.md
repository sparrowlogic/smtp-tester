## [Unreleased]

### Added

- First public release. An SMTP capture server on ports 1025/8025 with a web inbox, an RFC
  compliance validator that can reject non-compliant mail with a registered enhanced status code,
  an MCP server over streamable HTTP at `/mcp`, optional STARTTLS, optional write-through spooling
  to disk, and transport-level fault injection.
